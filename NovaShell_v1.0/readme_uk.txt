          NOVASHELL ENTERPRISE v5.0 - ПОСІБНИК ПРОЄКТУ
===================================================================

1. ПРО ПРОЄКТ:
   NovaShell — це професійна, enterprise-grade консоль для 
   адміністрування Windows, написана на чистому C++ з використанням 
   Win32 API, SCM, IP Helper та Winsock2. Має «хакерський» інтерфейс 
   та підтримку трьох мов (RU, UK, EN).

2. ШВИДКИЙ СТАРТ ТА ЗБІРКА (через MSYS2 / MinGW x64):
   Відкрийте термінал у папці проєкту та виконайте команду:
   g++ main.cpp -o novashell.exe -lpsapi -liphlpapi -lws2_32

3. СТРУКТУРА ФАЙЛІВ ПРОЄКТУ:
   - main.cpp          -> Головний вихідний код ядра та інтерфейсу NovaShell.
   - novashell.exe     -> Скомпільований виконуваний файл утиліти.
   - config.ini        -> Файл конфігурації для автозапуску застосунків.
   - novashell.log     -> Автоматичний системний журнал дій.
   - help_*.txt        -> Детальні вбудовані інструкції з команд.
   - readme_*.txt      -> Посібники розробника різними мовами.

4. СИСТЕМНІ ВИМОГИ:
   - ОС: Windows 10 / 11 (x64)
   - Права: Для керування службами Windows (команди 'srv') рекомендується 
     запуск від імені Адміністратора.
