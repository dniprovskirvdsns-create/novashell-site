          NOVASHELL ENTERPRISE v5.0 - РУКОВОДСТВО ПРОЕКТА
===================================================================

1. О ПРОЕКТЕ:
   NovaShell — это профессиональная, enterprise-grade консоль для 
   администрирования Windows, написанная на чистом C++ с использованием 
   Win32 API, SCM, IP Helper и Winsock2. Обладает «хакерским» интерфейсом 
   и поддержкой трёх языков (RU, UK, EN).

2. БЫСТРЫЙ СТАРТ И СБОРКА (через MSYS2 / MinGW x64):
   Откройте терминал в папке проекта и выполните команду:
   g++ main.cpp -o novashell.exe -lpsapi -liphlpapi -lws2_32

3. СТРУКТУРА ФАЙЛОВ ПРОЕКТА:
   - main.cpp          -> Главный исходный код ядра и интерфейса NovaShell.
   - novashell.exe     -> Скомпилированный исполняемый файл утилиты.
   - config.ini        -> Файл конфигурации для автозапуска приложений.
   - novashell.log     -> Автоматический системный журнал действий.
   - help_*.txt        -> Подробные встроенные инструкции по командам.
   - readme_*.txt      -> Руководства разработчика на разных языках.

4. СИСТЕМНЫЕ ТРЕБОВАНИЯ:
   - ОС: Windows 10 / 11 (x64)
   - Права: Для управления службами Windows (команды 'srv') рекомендуется 
     запуск от имени Администратора.
