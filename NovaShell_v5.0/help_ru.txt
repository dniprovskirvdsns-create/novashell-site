[СИСТЕМА / sys]
  sys info             - Вывод общей статистики (Uptime, RAM, процессы).
  sys uptime           - Точное время работы текущей сеансовой сессии.
  sys whoami           - Имя текущего пользователя операционной системы.
  sys env              - Вывод всех переменных окружения (PATH и др.).
  sys save [файл]      - Экспорт снимка процессов в текстовый отчет.
  sys history          - Просмотр истории ранее введенных команд.
  sys color <цвет>     - Смена цвета текста (green, cyan, pink, brightred).
  sys cls              - Очистка экрана консоли.
  sys repair           - Авто-восстановление стандартных файлов (config.ini).
  sys openpath         - Открытие текущей папки проекта в Проводнике Windows.
  sys files            - Интерактивный вывод всех файлов и папок проекта.
  sys clearlog         - Очистка файла системного лога (novashell.log).
  sys reboot           - Мгновенная перезагрузка процесса NovaShell.

[ПРОЦЕССЫ / proc]
  proc list            - Список всех активных процессов и их потребления RAM.
  proc list sort mem   - Сортировка процессов по объему потребляемой памяти.
  proc list sort pid   - Сортировка процессов по их числовому ID.
  proc list sort name  - Сортировка процессов по алфавиту (имени).
  proc monitor         - Живой интерактивный монитор процессов (выход по ESC).
  proc find <имя>      - Поиск процесса по названию и вывод его RAM.
  proc kill <PID>      - Принудительное завершение процесса по его PID.
  proc killall <имя>   - Массовое завершение всех процессов с указанным именем.
  proc priority <PID> <level> - Смена приоритета (idle, normal, high, realtime).

[СЛУЖБЫ WINDOWS / srv]
  srv list             - Вывод списка всех служб Windows и их статусов.
  srv start <имя>      - Запуск системной службы Windows.
  srv stop <имя>       - Остановка системной службы Windows.

[СЕТЬ / net]
  net connections      - Инспектор активных TCP-соединений и PID процессов.

[КОНФИГУРАЦИЯ / conf]
  conf list            - Просмотр содержимого конфигурационного файла.
  conf add <путь>      - Добавление программы в автозапуск при старте.

[ОБЩИЕ КОМАНДЫ]
  lang <ru|uk|en>      - Переключение языка интерфейса (RU, UA, EN).
  start <путь>         - Запуск любых .exe, апплтов (.cpl) и оснасток (.msc).
  help                 - Вывод этого справочного руководства.
  exit                 - Анимированное завершение работы и выход.
