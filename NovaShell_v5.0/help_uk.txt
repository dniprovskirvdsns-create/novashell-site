        NOVASHELL ENTERPRISE v5.0 - ПОВНИЙ ДОВІДНИК КОМАНД

[СИСТЕМА / sys]
  sys info             - Виведення загальної статистики (Uptime, RAM, процеси).
  sys uptime           - Точний час роботи поточної сеансової сесії.
  sys whoami           - Ім'я поточного користувача операційної системи.
  sys env              - Виведення всіх змінних середовища (PATH тощо).
  sys save [файл]      - Експорт знімка процесів у текстовий звіт.
  sys history          - Перегляд історії раніше введених команд.
  sys color <колір>    - Зміна кольору тексту (green, cyan, pink, brightred).
  sys cls              - Очищення екрана консолі.
  sys repair           - Авто-відновлення стандартних файлів (config.ini).
  sys openpath         - Відкриття поточної папки проєкту у Провіднику Windows.
  sys files            - Інтерактивне виведення всіх файлів і папок проєкту.
  sys clearlog         - Очищення файла системного лога (novashell.log).
  sys reboot           - Миттєве перезавантаження процесу NovaShell.

[ПРОЦЕСИ / proc]
  proc list            - Список усіх активних процесів та їх споживання RAM.
  proc list sort mem   - Сортування процесів за обсягом споживаної пам'яті.
  proc list sort pid   - Сортування процесів за їх числовим ID.
  proc list sort name  - Сортування процесів за алфавітом (іменем).
  proc monitor         - Живий інтерактивний монітор процесів (вихід по ESC).
  proc find <ім'я>     - Пошук процесу за назвою та виведення його RAM.
  proc kill <PID>      - Примусове завершення процесу за його PID.
  proc killall <ім'я>  - Масове завершення всіх процесів із зазначеним ім'ям.
  proc priority <PID> <level> - Зміна пріоритету (idle, normal, high, realtime).

[СЛУЖБИ WINDOWS / srv]
  srv list             - Виведення списку всіх служб Windows та їх статусів.
  srv start <ім'я>     - Запуск системної служби Windows.
  srv stop <ім'я>      - Зупинка системної служби Windows.

[МЕРЕЖА / net]
  net connections      - Інспектор активних TCP-з'єднань та PID процесів.

[КОНФІГУРАЦІЯ / conf]
  conf list            - Перегляд вмісту конфігураційного файла.
  conf add <шлях>      - Додавання програми до автозапуску при старті.

[ЗАГАЛЬНІ КОМАНДИ]
  lang <ru|uk|en>      - Перемикання мови інтерфейсу (RU, UA, EN).
  start <шлях>         - Запуск будь-яких .exe, апплетів (.cpl) та оснасток (.msc).
  help                 - Виведення цього довідкового посібника.
  exit                 - Анімоване завершення роботи та вихід.
